Feature Selection for Linear Regression

What is feature selection?

  • How do we choose what variables to include in our model?
  • Up to now… we included all of them… probably not the best idea.
  • Advantage of linear regression: interpretability
  • Including every feature decreases interpretability and can increase variance.
  • Reasons for feature selection:
    • Improve model performance (reduce overfitting/variance)
    • Improve model interpretability
    • Reduce computational cost
  • Parsimony: simpler models are called more parsimonious.
  • Occam’s Razor: more parsimonious models are better than less parsimonious models, holding all else constant.

Types of feature selection

  • Subset selection: Forward/Backward/Best-Subset Selection
  • Shrinkage-based methods: LASSO and Ridge Regression (next lecture)
  • Dimension reduction: consider linear combinations of predictors (e.g., PCA)

Subset Selection

Forward Selection

  • Start from the empty model (no predictors)
  • At each step, add the single feature that improves fit the most
  • Repeat until a stopping criterion is met (AIC, BIC, CV error, etc.)
  • Greedy: never removes a feature once added

Backward Selection

  • Start from the full model (all \(p\) predictors)
  • At each step, remove the single least useful feature
  • Repeat until a stopping criterion is met
  • Requires \(n > p\) so the full model can be fit

Forward Selection

  1. Let \(\mathcal{M}_0\) denote the empty model.
  2. For \(k = 0, \ldots, p-1\):
    1. Consider all \(p - k\) models that augment the predictors in \(\mathcal{M}_k\) with one additional predictor.
    2. Choose the best among these \(p - k\) models, and call it \(\mathcal{M}_{k+1}\).
  3. Select a single best model from among \(\mathcal{M}_0, \ldots, \mathcal{M}_p\).
  • Pros: Computationally efficient (\(1 + \frac{p(p+1)}{2}\) models).
  • Cons: Not guaranteed to find the best possible model out of all \(2^p\) models.

Backward Selection

  1. Let \(\mathcal{M}_p\) denote the full model, which contains all \(p\) predictors.
  2. For \(k = p, p-1, \ldots, 1\):
    1. Consider all \(k\) models that contain all but one of the predictors in \(\mathcal{M}_k\), for a total of \(k - 1\) predictors.
    2. Choose the best among these \(k\) models.
  3. Select a single best model from among \(\mathcal{M}_0, \ldots, \mathcal{M}_p\) using cross-validated prediction error, \(C_p\) (AIC), BIC, or adjusted \(R^2\).
  • Pros: Computationally efficient.
  • Cons: Not guaranteed to find the best possible model. Requires \(n > p\) so that the full model \(\mathcal{M}_p\) can be fit.

Forward vs. Backward

Both fit \(1 + \frac{p(p+1)}{2}\) models — far fewer than \(2^p\). Forward works when \(n < p\); backward does not. Neither is guaranteed to find the globally best subset.

Forward-Backward Selection

  • Also called bidirectional stepwise selection
  • Start from the empty model (or any starting model)
  • At each step, consider both adding and removing a feature
  • Add the feature that most improves fit if it passes an entry threshold; remove any current feature that falls below a removal threshold
  • More flexible than pure forward or backward — can correct earlier mistakes
  • Cons: Still greedy, still no guarantee of finding the best subset

Best-Subset Selection

  1. Let \(\mathcal{M}_0\) denote the empty model
  2. For \(k = 1, 2, \ldots, p\):
    1. Fit all \(\binom{p}{k}\) models that contain exactly \(k\) predictors.
    2. Pick the best (according to some criterion) among these \(\binom{p}{k}\) models, and call it \(\mathcal{M}_k\).
  3. Select a single best model from among \(\mathcal{M}_0, \ldots, \mathcal{M}_p\).
    • Can use cross-validated prediction error, \(C_p\) (AIC), BIC, adjusted \(R^2\) etc…
  • Pros: Conceptually simple, guaranteed to find the best model for training data.
  • Cons: Computationally infeasible for large \(p\) (need to fit \(2^p\) models). Not very popular in practice.

Subset Selection in Python

  • scikit-learn provides an implementation for Forward/Backward Sequential Feature Selection: SequentialFeatureSelector
  • Also provides SelectKBest (univariate tests), SelectFromModel (model weights), RFE (Recursive Feature Elimination).
  • Note: Best-subset selection is not natively implemented in scikit-learn because it is computationally expensive and regularization (shrinkage-based) methods almost always perform better computationally and prediction-wise.

Summary of Subset Selection

  • Best-Subset: Guaranteed to find best subset for training data, but computationally intensive.
  • Forward Selection: Efficient, starts from empty model. Can be used when \(p > n\).
  • Backward Selection: Efficient, starts from full model. Cannot be used when \(p > n\).
  • Usually, Regularization methods (Lasso, Ridge) are preferred as they shrink coefficients and perform feature selection in a theoretically sound and computationally elegant way. We’ll learn these next!
