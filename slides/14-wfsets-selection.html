“Workflow Sets” in Python

  • scikit-learn does not have an exact equivalent to workflow_set.
  • The most standard Python approach is:
    1. Create un-fitted Pipeline objects blending transformers and models.
    2. Store them in a dictionary mapping model_name -> Pipeline.
    3. Iterate over the dictionary, evaluating each via cross_validate.
workflows = {
    # Linear Regression 
    "lm_knn_impute": Pipeline([('preproc', lm_knn_impute_ct), ('nzv', VarianceThreshold()), ('model', lm_model)]),
    "lm_mean_impute": Pipeline([('preproc', lm_mean_impute_ct), ('nzv', VarianceThreshold()), ('model', lm_model)]),
    "lm_median_impute": Pipeline([('preproc', lm_median_impute_ct), ('nzv', VarianceThreshold()), ('model', lm_model)]),
    
    # KNN 5 
    "knn5_knn_impute": Pipeline([('preproc', knn_knn_impute_ct), ('nzv', VarianceThreshold()), ('scale', StandardScaler()), ('model', knn5_model)]),
    "knn5_mean_impute": Pipeline([('preproc', knn_mean_impute_ct), ('nzv', VarianceThreshold()), ('scale', StandardScaler()), ('model', knn5_model)]),
    "knn5_median_impute": Pipeline([('preproc', knn_median_impute_ct), ('nzv', VarianceThreshold()), ('scale', StandardScaler()), ('model', knn5_model)]),
    
    # KNN 10
    "knn10_knn_impute": Pipeline([('preproc', knn_knn_impute_ct), ('nzv', VarianceThreshold()), ('scale', StandardScaler()), ('model', knn10_model)]),
    "knn10_mean_impute": Pipeline([('preproc', knn_mean_impute_ct), ('nzv', VarianceThreshold()), ('scale', StandardScaler()), ('model', knn10_model)]),
    "knn10_median_impute": Pipeline([('preproc', knn_median_impute_ct), ('nzv', VarianceThreshold()), ('scale', StandardScaler()), ('model', knn10_model)])
}

Fit Resamples

Now we map cross_validate across our dictionary of models:

results = []
for name, wf in workflows.items():
    cv_res = cross_validate(wf, X_train, y_train, cv=ames_folds, 
                            scoring=['neg_root_mean_squared_error', 'r2'])
    
    # Average across folds
    rmse = -cv_res['test_neg_root_mean_squared_error'].mean()
    r2 = cv_res['test_r2'].mean()
    
    results.append({'wflow_id': name, 'rmse': rmse, 'rsq': r2})

results_df = pd.DataFrame(results).sort_values(by='rmse')

Feature Selection for Linear Regression

What is feature selection?

  • How do we choose what variables to include in our model?
  • Up to now… include all of them… probably not the best
  • Advantage of linear regression: interpretability
  • Including every feature decreases interpretability
  • Reasons for feature selection:
    • Improve model performance
    • Improve model interpretability
  • Parsimony: simpler models are called more parsimonious
  • Occam’s Razor: more parsimonious models are better than less parsimonious models, holding all else constant

Types of feature selection

  • Subset selection: Forward/Backward/Best-Subset Selection
  • Shrinkage-based methods: LASSO and Ridge Regression
  • Dimension reduction: consider linear combinations of predictors

Subset Selection in Python

  • scikit-learn provides an implementation for Forward/Backward Sequential Feature Selection: SequentialFeatureSelector
  • Also provides SelectKBest, SelectFromModel, RFE (Recursive Feature Elimination).
  • regularization (shrinkage-based) methods almost always perform better computationally and prediction-wise than exhaustive best-subset.
