What are SHAP Values?

Motivation

  • MDI and permutation importance tell us which features matter globally — across all predictions
  • But what if we want to explain one specific prediction?
    • Why did the model predict this person is an “always” voter?
    • Which features pushed that prediction up, and which pulled it down?
  • SHAP (SHapley Additive exPlanations) answers exactly this question
  • Key difference from MDI and permutation importance: SHAP explains individual predictions, not just the overall model — and individual explanations can be aggregated for global summaries

What are SHAP Values?

  • Grounded in cooperative game theory
  • Treat each feature as a “player” in a game where the “payout” is the model’s prediction
  • A Shapley value for feature \(j\) answers: on average across all possible subsets of features, how much does including feature \(j\) change the prediction?
  • The result is a contribution score for each feature, for each individual observation

Shapley Values: Intuition

For a single prediction \(\hat{f}(x)\):

\[\hat{f}(x) = \underbrace{\mathbb{E}[\hat{f}]}_{\text{base value}} + \sum_{j=1}^{p} \phi_j\]

  • \(\mathbb{E}[\hat{f}]\): the model’s average prediction across all training data (base value)
  • \(\phi_j\): the SHAP value for feature \(j\) — how much it pushed this prediction up or down
  • The SHAP values sum exactly to the difference between the prediction and the base value

This is called the efficiency property — one of four fairness axioms Shapley values satisfy

Local Explanations: Waterfall Plot

A waterfall plot explains a single prediction:

  • Starts at the base value (average prediction)
  • Each feature adds or subtracts its SHAP value
  • Ends at the actual predicted value for that observation
  • Features shown in order of magnitude: largest contributors at top

Useful for: explaining a model’s decision to a stakeholder, debugging surprising predictions, auditing for fairness

Global Explanations: Aggregating SHAP

Aggregate local SHAP values across many observations for global summaries:

  • Bar plot: mean \(|\phi_j|\) across all observations — ranks overall importance
  • Beeswarm plot: shows both importance and direction — each dot is one observation, color encodes feature value (red = high, blue = low), x-axis = SHAP value

The beeswarm plot is the most information-rich global summary: it shows not just which features matter, but how they affect predictions

SHAP: Pros and Cons

Pros:

  • Local + global: explains individual predictions and overall model behavior
  • Theoretically grounded: Shapley values satisfy fairness axioms (efficiency, symmetry, dummy, additivity)
  • Rich built-in visualizations
  • Consistent across model types (unlike MDI)

Cons:

  • Slower than MDI (though TreeExplainer is fast)
  • Correlated features: SHAP values can be unintuitive when features are highly correlated — similar to permutation importance
  • Multi-class output can be harder to summarize (one set of SHAP values per class)

All Three Methods: Summary

Method Scope Model-agnostic? Data used Per-prediction?
MDI Global No (trees only) Training No
Permutation Global Yes Test No
SHAP Local + Global Yes (speed varies) Either Yes
  • Use MDI for fast, exploratory importance during model development
  • Use Permutation for a model-agnostic global benchmark on test data
  • Use SHAP when you need to explain individual predictions or want the richest global summary
