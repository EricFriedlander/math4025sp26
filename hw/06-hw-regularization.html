Homework 6: Feature/Model Selection and Regularization

Author

Your Name

Introduction

In this homework you will practice using regularization and model tuning to select models and features.

Learning goals

In this assignment, you will…

  • Fit linear regression models using Ridge and LASSO regularization
  • Fit logistic regression models using \(L_1\) regularization
  • Use grid-based techniques to choose tuning parameters
  • Explore your group’s project dataset and prepare an EDA presentation

Getting Started

There are two parts to this homework. The first part is focused on your group project dataset and will be completed in your project repository. The second part is focused on a separate dataset about NFL field goals and will be completed in this homework repository. You should complete both parts of the assignment, but they are independent of each other.

Teams & Rules

Complete part 1 of this homework in your project teams. The following rules apply to all team assignments:

  1. You are all responsible for understanding the work that your team turns in.
  2. All team members must make roughly equal contributions to the homework.
  3. Any work committed to a repository must be committed and pushed by the person who wrote that work.

Logistic Regression and Regularization

We will now extend what we’ve learned about \(L_1\)-regularization to logistic regression! In the same way that LASSO adds an \(L_1\)-norm penalty to the objective function for Ordinary Least Squares regression, we can add an \(L_1\)-norm penalty to the objective function for logistic regression. Whereas in OLS the objective function was the sum of squared errors, the objective function for logistic regression is the log-likelihood. Other than this, the principle works the same way: by including an \(L_1\)-regularization term, you induce sparsity.

In sklearn, logistic regression with \(L_1\) regularization is fit using using the following error term:

\[ \frac{1}{c}\left(\frac{\mathtt{l1\_ratio}}{n}\lVert\beta\rVert_2 + (1-\mathtt{l1\_ratio})\lVert\beta\rVert_1\right) \]

This is equivalent to elastic net regularization, where l1_ratio controls the balance between \(L_1\) and \(L_2\) regularization. To get pure \(L_1\) regularization, you would set l1_ratio=1. The c parameter is the inverse of the regularization strength (where c = 1 / alpha), so smaller c means more regularization.
