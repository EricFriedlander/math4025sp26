Homework 8: Classification Trees and Random Forests

Author

Your Name

Introduction

In this homework we will practice fitting classification trees and random forests. There are two parts: an individual portion where you work with a dataset of your choice, and a group portion where you apply random forests to your project data and prepare a short presentation.

Learning goals

In this assignment, you will…

  • Fit and interpret classification trees
  • Fit random forests and use variable importance plots to interpret them
  • Use cross-validation and grid search to tune model parameters
  • Apply random forests to your group’s project dataset

Getting Started

Exercise 0

TipQuestion

Click this link to accept the assignment and clone it to your computer.

There are two parts to this homework. Part 1 is an individual analysis of a dataset either a titanic data set or the NFL field goals dataset and will be completed in this homework repository. Part 2 is focused on your group project dataset and will be completed in your project repository. You should complete both parts, but they are independent of each other.

Part 1: Individual Analysis

NoteDataset Choice

For Part 1, you may use either of the following datasets in the data/ directory:

  • Titanic: Titanic_train.csv and Titanic_test.csv.
  • NFL Field Goals (from HW-06): nfl-fg-data.xlsx.

Pick one and stick with it throughout Part 1. The exercises are written with the Titanic dataset in mind, but all steps apply equally to the NFL dataset — where Titanic-specific context is given, substitute the equivalent for the NFL data (e.g., predicting Made instead of Survived).

Data: Titanic

The Titanic dataset includes passenger information and whether each passenger survived. The variables are:

  • Survived: whether the passenger survived (1) or died (0)
  • Pclass: passenger class (1st, 2nd, or 3rd)
  • Sex: sex of the passenger
  • Age: age in years (NaN if unknown)
  • SibSp: number of siblings/spouses aboard
  • Parch: number of parents/children aboard
  • Fare: fare paid
  • Embarked: port of embarkation (C = Cherbourg, Q = Queenstown, S = Southampton)

Data: NFL Field Goals

If you are using the NFL dataset, refer to HW-06 for variable descriptions. Your target variable is Made (1 = field goal made, 0 = missed).

Exploratory Data Analysis

Exercise 1

TipQuestion

Load your chosen dataset(s) (training and test splits if applicable). Inspect the data and perform any cleaning you think is necessary (e.g., dropping ID or row-number columns, correcting data types). Based on domain knowledge, which two or three features do you expect to be most predictive of the outcome? Give a brief justification for each.

Exercise 2

TipQuestion

Conduct a brief EDA exploring the relationship between the outcome and the variables you identified in Exercise 1. Use plots rather than tables where possible, display and interpret each plot one at a time, and aim for a professional presentation.

Pre-Processing

Exercise 3

TipQuestion

Build a preprocessing pipeline using ColumnTransformer and Pipeline suitable for both a classification tree and a random forest. Think carefully about what preprocessing is needed — decision tree-based models do not require normalization, but there are still other steps to consider.

Classification Tree

Exercise 4

TipQuestion

Fit a DecisionTreeClassifier from sklearn.tree to the training data using your pipeline. Visualize the tree with sklearn.tree.plot_tree. Based on the tree, which variables appear most important?

Exercise 5

TipQuestion

Evaluate your classification tree on the test set. Report accuracy and display a confusion matrix using ConfusionMatrixDisplay from sklearn.metrics. Comment on where the tree makes mistakes.

Random Forest

Exercise 6

TipQuestion

Fit a RandomForestClassifier from sklearn.ensemble to the training data. Without doing any tuning, choose values you think are reasonable for n_estimators (number of trees) and max_features (number of features considered at each split). Evaluate it on the test set and compare its accuracy to the classification tree from Exercise 5.

Exercise 7

TipQuestion

Generate a variable importance plot using the feature_importances_ attribute of your fitted random forest. How do the variables identified as important compare to what the classification tree highlighted in Exercise 4?

Exercise 8

TipQuestion

Use GridSearchCV with StratifiedKFold to tune max_features. You don’t need to tune n_estimators but make sure it’s large enough that you accuracy isn’t changing much if you increase it further. Use accuracy as your scoring metric. Tip: Use caching or save your CV results so you don’t re-run cross-validation every time the document is rendered.

Exercise 9

TipQuestion

Fit your best model from Exercise 8 to the full training data and evaluate it on the test set. How does the tuned model’s accuracy compare to the untuned random forest from Exercise 6?

Conceptual Questions

Exercise 10

TipQuestion

Discuss max_features in the context of the bias-variance trade-off. How should increasing or decreasing max_features affect the flexibility, bias, and variance of the resulting forest?

Exercise 11

TipQuestion

Compare the variable importance plot from Exercise 7 with the visualization of the classification tree from Exercise 4. What information does each one convey? Is there anything you can learn from one that you cannot learn from the other? Which is more useful for communicating results to a non-technical audience?

Part 2: Group Work

ImportantWhere to submit Part 2

Complete Exercises G1–G4 in your project repository, not in this homework repo. Add a new file called 02-modeling-overview.qmd to the root of your project repo and complete the exercises there. Submit this part by committing and pushing to your project GitHub Classroom repository.

In Part 2, you will apply what you have learned about random forests to your group’s project dataset. Refer to the project instructions and your 01-eda.qmd from HW-06 for context on the data and your assigned target variable.

Exercise G1: Presentation Preparation

TipQuestion

Prepare a 5-minute group presentation to be delivered in class on Thursday, April 23rd. Your presentation should cover:

  1. A brief reminder of your target variable, what it measures, and any important features of the data (e.g. skew, missing values, etc.)
  2. A description of the models that you’ve fit so far, how you’ve tuned (or plan to tune) them, and any challenges you’ve encountered. You should have tested out at least three different types of models: logistic regression, random forest, and at least one more model of your choice.
  3. A description of the performance of your models, including how you evaluated them and how they compare to each other.
  4. A brief description of what your group plans to investigate next or any open questions you have.

You should present from a set of slides and be prepared to answers questions from the audience. All group members should be prepared to speak.
